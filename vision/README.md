# vision — YOLO 문서 검출 지속 학습

팀원 누구나 **사진이 생기면 넣고, 검수하고, 학습**할 수 있게 만든 도구입니다.
사진·라벨·모델은 git 이 아니라 **팀 구글 드라이브 공유 폴더**에 모읍니다(실사 이미지 커밋 금지 규칙).

```
 촬영 ──▶ inbox ──[ingest]──▶ review ──[라벨 검수]──▶ [build] ──▶ dataset ──[train]──▶ models
 (누구나)  사진 넣기   EXIF 삭제·중복 제거      label_tool.html      검수본만        더 나으면 current 교체
                       초벌 라벨(현재 모델)                                              │
                          ▲──────────────────────────────────────────────────────────────┘
                          모델이 좋아질수록 초벌 라벨이 정확해져 검수가 빨라진다
```

- **ingest·build·train** 은 Colab 노트북(`vision/colab.ipynb`)이나 내 PC 명령어 어느 쪽으로든 실행합니다. 결과는 같은 드라이브 폴더에 쌓입니다.
- **라벨 검수**는 내 PC 크롬에서 공유 폴더의 `라벨검수도구.html` 을 열어 합니다. 저장소를 받지 않아도 되고, 사진은 내 컴퓨터 밖으로 나가지 않습니다.
- 지금은 **학습 환경까지**입니다. 서비스(`pipeline/`)에 검출기를 붙이는 일은 별도 PR 로 합니다.

## 1. 사진 넣기 — 누구나

`inbox/` 안에 **묶음 폴더**를 만들어 넣습니다. 폴더 이름은 `이름_소품_날짜` 처럼 씁니다.

```
inbox/찬영_학생증A_1007/IMG_0001.jpg ...
inbox/다인_송장3종_1008/...
```

- **묶음 = 같은 소품·같은 장소에서 찍은 사진들**입니다. 학습/검증/시험 분할을 묶음 단위로 해서, 같은 학생증이 학습과 시험에 동시에 들어가지 않게 합니다. 묶음을 너무 크게 만들지 마세요(10~30장 권장).
- 휴대폰 원본(JPG·HEIC) 그대로 넣으면 됩니다. 위치정보는 ingest 때 지워지고, inbox 원본도 그때 삭제됩니다.

**촬영 규칙**
- **가상 정보로 만든 소품만** 찍습니다. 실제 내 학생증이나 타인의 개인정보가 보이면 안 됩니다(PRD 데이터 윤리).
- 같은 소품을 **거리(가까이·멀리), 각도, 조명, 배경, 흔들림**을 바꿔 가며 찍습니다. 사진 속에서 작게 나오는 경우가 특히 중요합니다.
- **물체가 없는 사진도** 일부 넣습니다(책상, 책 표지, 간판 등). 오탐을 줄이는 데 쓰입니다.
- 사람이 겨우 읽을 정도로 흐린 사진도 넣습니다. 교수님 피드백 "사람은 읽는데 OCR 이 못 읽는 경우"를 잡으려는 데이터입니다.

## 2. 초벌 라벨 — 누구나 (ingest)

Colab 2번 칸, 또는 내 PC 에서:

```bash
python -m vision ingest --root "G:/내 드라이브/PrivacyLens-YOLO" --who 찬영
```

`--root` 대신 환경변수 `PL_YOLO_ROOT` 를 한 번 설정해 두면 생략할 수 있습니다.

## 3. 라벨 검수 — 누구나

1. 공유 폴더의 **`라벨검수도구.html`**(= `vision/label_tool.html` 사본)을 **크롬이나 엣지**로 엽니다. 파일을 브라우저 창에 끌어다 놓으면 됩니다.
2. **폴더 열기** → `PrivacyLens-YOLO` (또는 그 안의 `review`) 를 고르고 편집 권한을 허용합니다.
3. 초벌 박스를 고치고 **Enter**(검수 완료) / 쓸 수 없는 사진은 **X**(제외).

| 조작 | 키 |
|---|---|
| 새 박스 | 빈 곳 드래그 (선택된 클래스로) |
| 클래스 선택·변경 | 1 ~ 6 |
| 박스 이동·크기 | 박스 드래그 / 모서리 드래그 |
| 삭제 / 되돌리기 | Delete / Ctrl+Z |
| 확대 / 이동 / 맞춤 | 휠 / Space+드래그·오른쪽 드래그 / F |
| 이전·다음 | ← → (고친 박스는 저장됨, 완료 표시는 안 됨) |

- 물체가 하나도 없는 사진도 **그대로 Enter** 합니다.
- 두 사람이 같은 사진을 동시에 검수하지 않게, 단톡방에 "검수 시작"을 알리거나 나눠서 합니다.
- 데스크톱 앱이 없으면: 드라이브에서 `review` 폴더를 내려받아 검수한 뒤 `labels/` 와 `done/` 폴더를 다시 올립니다.

## 4. 데이터셋 반영 + 학습 — 누구나 (GPU 있는 사람 또는 Colab)

```bash
python -m vision build --who 찬영     # 검수 완료(.ok)만 dataset 으로. 미검수 초벌 라벨은 절대 학습에 안 씀
python -m vision train --who 찬영     # GPU 자동 사용. --epochs 60 --imgsz 1280 기본
```

- 학습은 **지금 모델(current)에서 이어서** 합니다.
- 끝나면 새 모델과 지금 모델을 **같은 시험 사진**으로 다시 채점해서, 같거나 좋을 때만 `current` 로 바꿉니다. 나빠진 모델은 `models/vNNN/` 에 남기만 합니다(`--force` 로 강제 교체 가능).
- 기록은 `models/history.csv`, 버전별 상세는 `models/vNNN/metrics.json`(클래스별 AP50 포함).
- 시험 점수는 **직접 찍은 사진(val·test)으로만** 냅니다. 합성 사진은 학습에만 씁니다. 실사 묶음이 3개 미만이면 검증 데이터가 없어 점수가 의미 없다는 경고가 나옵니다.

## 폴더 구조

```
PrivacyLens-YOLO/
  inbox/        ① 새 사진 (묶음 폴더별)
  review/       ② 검수 대기: images/ labels/ done/ classes.json
  dataset/      ③ 검수 완료: images/ labels/ train.txt val.txt test.txt data.yaml
  models/       ④ v001/ v002/ ... current.txt history.csv
  manifest.csv  사진별 묶음·출처·분할·상태 (엑셀로 열림)
  라벨검수도구.html  검수 도구 (명령을 실행할 때마다 최신 버전으로 갱신)
  작업중.lock    누가 ingest·build·train 중일 때만 생김
```

## 자주 묻는 것

- **"다른 사람이 작업 중입니다"** — 동시에 돌리면 `manifest.csv` 가 꼬여서 막아 둔 것입니다. 3시간이 지나면 자동으로 풀리고, 확실히 아무도 안 쓰면 `작업중.lock` 을 지워도 됩니다.
- **클래스를 추가하고 싶다** — `classes.py` 맨 뒤에 추가 → `python -m vision init` (검수 도구 목록 갱신) → 기존 모델과 클래스가 달라 `yolo11n.pt` 부터 다시 학습됩니다.
- **같은 사진을 또 넣었다** — 파일 내용 해시로 걸러지므로 한 장만 남습니다.
- **Colab 세션이 끊겼다** — 학습 칸만 다시 실행합니다. 끊긴 학습은 저장되지 않고, 데이터는 드라이브에 그대로 있습니다.

## 참고

- 학습 라이브러리 Ultralytics(YOLO11)는 **AGPL-3.0** 입니다. 공개 저장소에서 수업 프로젝트로 쓰는 데는 문제없지만, 상용 배포 시에는 라이선스를 다시 확인해야 합니다.
- 합성 생성기(`vision/synth.py`)는 `samples/make_sample.py` 의 가상 송장과 직접 그린 가상 학생증(얼굴 대신 실루엣)을 씁니다.
