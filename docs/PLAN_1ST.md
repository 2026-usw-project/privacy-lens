# 1차 완성 계획 (2026-11-01 작성)

새 기능은 2차로 미루고, 지금 있는 흐름(올리기 → 읽기 → 판단 → 가리기 → 저장)을 **실사 사진 기준으로 안정화**한다.
판단 근거와 측정 방법이 생겼으므로, 무엇을 고칠지는 숫자를 보고 정한다.

## 지금 문제

| # | 문제 | 근거 |
|---|---|---|
| 1 | 형식 없는 개인정보(라벨 없는 이름, 비밀번호, 계좌, 학번)를 판단하지 못한다 | `eval.judgment` 기준선: 이름 35/112, 비밀번호 0/28, 계좌 0/14, 학번 0/14 |
| 2 | 실사 성능을 잰 적이 없다 | YOLO v001~v004 의 val·test 0장. 0.995 는 합성 학습 사진 점수 |
| 3 | 놓친 원인(못 찾음 / 잘못 읽음 / 판단 실패)을 나눠 본 적이 없다 | → `eval.failures` 로 나눈다 |
| 4 | 무엇을 가릴지 기준이 합의되지 않았다 | → `docs/MASKING_CRITERIA.md` 초안 |
| 5 | YOLO 의 역할이 증명되지 않았다 | 실사 비교 없음. 서버는 가장 큰 버전 폴더를 자동으로 쓴다 |
| 6 | 개인 메일이 근처 '고객센터' 때문에 참고로 떨어진다 | `eval.judgment` 메일 화면 장면 14/14 → **고침** |

## 1차 완료 기준 (제안, 팀 합의 필요)

실사 시험용 사진 20장(`docs/REAL_PHOTO_GUIDE.md`) 기준.

| 항목 | 기준 | 측정 |
|---|---|---|
| 놓침 | 가림 정답의 90% 이상을 가림으로 | `eval.failures` 의 가림 / 가림정답 |
| 오탐 | 가리면 안 될 것을 가림 0~1개, 정답 밖 가림 사진당 1개 이하 | 잘못가림, 정답밖가림 |
| 가림 확인 | 가린 뒤 재검사에서 남은 것 0개 | 서버 `/redact` 재검사 |
| 속도 | 사진 1장 10초 이내(서버) | 화면 하단 처리 시간 |
| 안정성 | 30장 연속 처리 오류 0번 | 같은 평가 |

## 개발 환경 (준비 완료)

| 도구 | 하는 일 | 명령 |
|---|---|---|
| 판단 평가 | 가상 텍스트 182장면으로 판단 규칙만 잰다. **지금 규칙으로 포화(100%)라 개선 측정보다 회귀 방지용** | `python -m eval.judgment` |
| 이름 후보·NER 비교 | 따로 모은 이름·낱말 목록, 규칙 vs Kiwi vs HF NER | `python -m eval.names_check`, `python -m eval.ner_compare` |
| 안정성 점검 | 이상한 입력·연속 30장·동시 4명·가림 한 바퀴 | `python -m eval.stability` |
| 판단 회귀 검사 | 기준선보다 나빠지면 실패(CI 가 PR 마다 실행) | `python -m eval.judgment --check` / 좋아지면 `--update` |
| 실사 실패 원인 | 사진 + 정답 → ①②③ 비율, `평가기록.csv` 누적 | `python -m eval.failures run <폴더> --note "…"` |
| 위치정보 지우기 | 공유 폴더에 올리기 전 EXIF 제거 | `python -m eval.failures strip <폴더>` |
| 정답 입력 도구 | 브라우저에서 사진별 정답 입력, 소품 번호로 자동 채움 | `python -m eval.failures init <폴더>` → `정답입력도구.html` |
| 촬영용 소품 | 가상 개인정보 인쇄물(PDF) + 정답(`props.json`) | `python -m samples.props <폴더>` |
| Colab 평가 | PaddleOCR 설치부터 평가·YOLO 비교까지 | `eval/colab_eval.ipynb` |
| CI | 테스트(3.10·3.12·3.13), 판단 회귀, 화면 점검·빌드 일치, 합성 한 바퀴 | `.github/workflows/ci.yml` |
| PR·이슈 양식 | 확인 목록, 놓침·오탐 사례(사진 없이 가짜 값으로) | `.github/` |

NER 추가 학습, 로컬 LLM 판단 보조, 보안정보 모드(부대마크 등), 여러 장 한꺼번에 검사, 캡처 화면 모드, APK·브라우저 확장, 동영상, YOLO 실사 대량 학습, 공개 데이터셋 도입.
