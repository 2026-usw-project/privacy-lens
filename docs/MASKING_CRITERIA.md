# 가림 기준표 (초안, 2026-11-01)

판단 코드(`pipeline/context.py`)와 판단 평가(`eval/judgment.py`)가 따르는 기준이다.
**팀 합의 전 초안**이다. 바꾸면 `eval/judgment.py` 의 정답도 같이 바꾼다.

## 원칙

1. **혼자서 특정 개인을 알아볼 수 있거나, 다른 정보와 합쳐 그렇게 되는 것**을 가린다.
2. **놓침이 오탐보다 나쁘다.** 애매하면 '확인 필요'로 올린다. 단, '가림'으로 단정하지는 않는다.
3. **공개된 정보**(가게·기업이 일부러 알리는 번호·주소·상호)는 가리지 않는다.
4. 판단 근거(옆의 라벨, 문서 종류)를 사용자에게 보여 줄 수 있어야 한다.

## 등급

| 등급 | 코드 값 | 뜻 |
|---|---|---|
| 가림 | `cover` | 자동으로 가림 대상에 넣는다 |
| 확인 필요 | `review` | 사용자에게 보여 주고 고르게 한다 |
| 참고 / 무시 | `info` / 없음 | 가리지 않는다 |

## 팀이 정해야 할 것 (미결)

- **라벨 없는 이름 후보를 '확인 필요'로 올릴지.** 올리면 놓침이 줄고 오탐(상호·지명)이 늘어난다. 초안은 올리는 쪽이다.
- **학교·회사명 단독**을 확인 필요로 볼지. 초안은 이름 옆일 때만 본다.
- 메신저 캡처 속 **대화 상대 이름**(화면 위쪽 대화방 제목)도 같은 기준인지.
- 영수증의 **일부 가려진 카드번호**는 무시해도 되는지.
- 화면이 지금 **'가림' 등급도 기본으로 선택하지 않는다**(`web/frontend-demo/dist/core.js`, `enabled:false`).
  위 원칙 2(놓침이 더 나쁨)와 맞추려면 '가림'은 기본 선택, '확인 필요'는 기본 해제가 맞다. 문서화된 결정이 없어 그대로 두었다.
