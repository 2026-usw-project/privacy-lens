## Platform

web

## Users

SNS·중고거래에 사진을 올리려는 일반 사용자, 업무 자료·학습 화면을 공유하는 직장인·학생. 사진의 주인공에 집중하느라 배경의 택배 송장·학생증·모니터 화면을 놓친 상태에서, 올리기 직전에 한 번 확인하려는 상황입니다. 발표장에서는 심사자·청중이 90초 안에 흐름을 이해해야 합니다.

## Product Purpose

사진 배경의 개인정보를 찾아 **위치와 근거**를 보여 주고, 사용자가 확인·수정한 영역만 가린 뒤 촬영 메타데이터(EXIF)를 제외한 사본을 저장하게 합니다. 자동으로 가려서 올리지 않습니다. 무엇을 가릴지는 사용자가 정합니다.

## Positioning

한국 문서(송장·학생증·한국 주소)에 맞춘 판정, 원본 해상도로 작은 배경 글자를 판독, 점수 대신 "어디서 무엇이 왜 위험한지"를 박스와 문장으로 설명.

## Operating Context

업로드 → 분석 → 결과 확인·수정(박스 추가·삭제·이동·크기, 유형 변경, 좌표 입력) → 가림 방식 선택 → 저장. 데스크톱 브라우저 발표 시연이 주 사용 장면이고, 모바일 폭(390px)에서도 동작해야 합니다.

## Capabilities and Constraints

- 분석은 Privacy Lens 서버(PL2 백엔드)의 실제 OCR·판정입니다. 결과는 단정이 아니라 권장(가림 권장·검토 권장·참고)으로 보여 줍니다.
- 외부 글꼴·이미지·추적 코드를 쓰지 않습니다. 브라우저 저장소는 가리는 방식 기억에만 씁니다.
- 좌표는 방향 보정 후 원본 픽셀 기준입니다.
- 성능 수치(재현율 85% 등)는 목표이며 측정 결과로 표시하지 않습니다.
- 서버 규격은 `API_CONTRACT.md`. 가림·미리보기·검증은 서버가 하고 화면은 결과를 보여 줍니다.

## Brand Commitments

- 이름 Privacy Lens(프라이버시 렌즈), 렌즈 아이콘 유지.
- 시각 언어는 Firecrawl 대시보드·랜딩의 **스타일만** 참고합니다(웜 오프화이트, 주황 포인트, 얇은 격자선, 모노 대괄호 라벨). Firecrawl의 이름·로고·불꽃 아이콘은 쓰지 않습니다.

## Evidence on Hand

코드로 생성한 가상 샘플 3종(송장·학생증·복합 문서)과 세로 샘플. 실사진·실제 개인정보·사용자 후기·측정된 성능 수치는 없으며 만들어 내지 않습니다.

## Product Principles

1. 사용자가 최종 결정한다. 탐지는 제안이고 가림은 확인 후에만.
2. 근거를 보여 준다. 모든 박스에는 이유가 붙는다.
3. 사진은 기본적으로 브라우저 밖으로 나가지 않는다.
4. 시뮬레이션과 실제 분석을 혼동하게 만들지 않는다.

## Accessibility & Inclusion

키보드로 박스 이동·크기 조절, 대화상자 포커스 복귀, 본문 대비 4.5:1 이상, 동작 줄이기 설정 존중.
