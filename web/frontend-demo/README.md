# Privacy Lens · 프라이버시 렌즈

> 이 폴더는 5번 프론트엔드 담당의 독립 UI 시연본입니다.
> 기존 React 앱(`web/src`)과 서버를 변경하지 않습니다.
> 제안 API는 현재 팀 스키마와 호환되지 않으므로 기본 데모 모드로 사용하세요.
> 차이와 합의가 필요한 내용은 [INTEGRATION_NOTES.md](INTEGRATION_NOTES.md)를 확인하세요.

사진을 공유하기 전 개인정보 영역을 확인하고 가리는 프론트엔드 데모입니다.
아이보리·그린 작업 화면에서 업로드 → 분석 → 결과 수정 → 가림·저장을 시연합니다.

## 실행

Node.js 18 이상에서 이 폴더를 연 다음:

```powershell
npm run dev
```

npm 명령을 사용할 수 없고 node만 있다면 `node server.mjs`로 실행해도 됩니다.

브라우저에서 http://127.0.0.1:4173 을 엽니다. 의존성이 없어 npm install은 필요 없습니다.
로컬 서버는 정적 화면만 제공합니다. 분석 서버는 포함되어 있지 않습니다.

설치 없이 열려면 `privacy-lens.html`을 Chrome/Edge에서 여세요.
Codex 내장 브라우저에서 로컬 파일 열기가 제한되면 위 로컬 서버 방식을 사용하세요.
서버 연동은 로컬 HTTP 화면에서 사용하는 것을 권장합니다.

## 바로 시연하기

상단 **90초 시연 시작**을 누르면 복합 문서의 오탐·미탐 수정 시나리오를 실행합니다.
화면의 체크리스트를 따라 근거 확인 → SAMPLE 오탐 삭제 → 이메일 영역 추가 →
가림 미리보기 → PNG 저장을 진행합니다.

[발표 시나리오와 팀 사용성 점검](DEMO_GUIDE.md)을 함께 준비했습니다.

## 구현 범위

- JPG·PNG·WEBP 파일 선택 / 드래그 업로드, 파일 미리보기, 분석 시작·진행·취소·실패·재시도
- 가상 송장·학생증·복합 문서와 세로 사진 샘플
- 정상, 오탐·미탐, 일부 판독 실패, 탐지 없음, 분석 실패 시나리오
- 사진 박스와 유형·근거 목록의 양방향 선택 연결
- 직접 영역 그리기 / 중앙 추가, 이동·크기 변경, 삭제·되돌리기, 가림 선택·해제
- 원본 픽셀 좌표 입력과 개인정보 유형 수정
- 50–400% 확대, 화면 맞춤, 확대 화면 스크롤
- 모자이크·블러·단색, 강도, 원본·가림 결과·전후 비교
- 최종 PNG 미리보기, 원본 해상도의 브라우저 다운로드
- 최종 영역 JSON 확인 / 다운로드
- 선택적 팀 서버 연결: 분석 요청, 결과 검증, 최종 영역 전송, 서버 PNG 다운로드

방향키는 선택된 박스를 1% 이동합니다. Shift를 누르면 0.1%, Alt를 누르면 크기를 바꿉니다.
작은 박스는 확대한 다음 편집하거나 숫자로 수정하세요.

## 실제 분석과 데모의 차이

**기본 모드는 프론트엔드 시뮬레이션이며 실제 YOLO·OCR·언어 모델이 아닙니다.**
샘플 영역은 미리 정의되어 있습니다. 내 사진에는 가상의 탐지 결과를 만들지 않습니다.
서버 미연결 상태에서는 직접 가릴 영역을 지정합니다.

**데모 · 서버 미연결** 버튼에서 팀 서버 주소를 설정할 수 있습니다.
서버 분석은 사용자가 업로드한 사진에만 적용되며, 샘플은 항상 로컬 시뮬레이션입니다.
실제 서버는 팀에서 구현해야 합니다. 주소를 설정하는 것만으로 사진이 전송되지는 않습니다.
연동 규격과 책임 범위는 [API_CONTRACT.md](API_CONTRACT.md)를 확인하세요.

9종 중 송장·학생증·모니터 외 대상은 데모용 제안입니다. 최종 연구 범위에 맞게 조정하세요.
재현율 85%, 오탐률 15%, 평균 5초는 프로젝트 목표이며 이 데모에서 측정한 성능이 아닙니다.

## 개인정보와 파일 처리

- 기본 데모에서는 메모리에서만 처리하며 사진을 외부로 보내지 않습니다.
- localStorage·IndexedDB·추적 코드·외부 글꼴·외부 이미지 요청을 사용하지 않습니다. 글꼴은 `dist/fonts/`에서 자체 제공합니다.
- 서버 모드에서는 분석 및 최종 저장 시, 선택한 서버에 방향 보정·PNG 변환된 사진을 보냅니다.
- 원본 파일을 수정하지 않습니다. 새 PNG를 만듭니다.
- JPEG EXIF의 GPS·기기·촬영 시각 **태그 존재 여부**를 검사합니다.
- PNG·WEBP의 원본 메타데이터 검사는 구현하지 않았으며 화면에 표시합니다.
- Canvas 재인코딩은 원본 EXIF·XMP를 복사하지 않습니다. 사진에 찍힌 글자는 직접 가려야 합니다.
- 모자이크·블러에는 정보가 남을 수 있습니다. 완전하게 덮으려면 단색을 선택하세요.
- 파일은 최대 20 MiB / 24 MP / 한 변 16,384 px로 제한합니다.
- 애니메이션 이미지는 브라우저에서 불러온 정지 프레임 한 장을 편집합니다.
- 서버의 원본 삭제·로그·보관 정책은 프론트엔드가 보장할 수 없으며 백엔드에서 구현해야 합니다.

## 개발

```powershell
npm run check
npm run build
```

`dist`가 편집 원본입니다. build는 이를 묶어 `privacy-lens.html`을 생성합니다.
npm 없이도 `node scripts/check.mjs`, `node scripts/check-contract.mjs`,
`node scripts/build.mjs`를 각각 실행할 수 있습니다. 이번 환경에서는 이 방식으로 검증했습니다.

| 파일 | 역할 |
|---|---|
| dist/index.html | 화면과 대화상자 |
| dist/styles.css | 디자인 토큰·반응형·편집 화면 (한 파일, `:root` 토큰 기준) |
| dist/fonts/ | Pretendard 한글 서브셋 4종(OFL, `LICENSE.txt`) · 외부 요청 없이 자체 제공 |
| dist/app.js | 업로드, 샘플, 편집, 메타데이터, 렌더링 |
| dist/core.js | 좌표 변환, 결과 검증, 전송 데이터 |
| dist/api.js | 선택적 서버 통신 어댑터 |
| scripts/check.mjs | 문법·정적 참조·EXIF·샘플 검사 |
| scripts/check-contract.mjs | 좌표·계약·통신 오류 검사 |
| server.mjs | 로컬 정적 서버 |

## 검증과 남은 작업

자동 검사 67개: 문법·DOM 참조·파일 형식·EXIF 오류 처리·샘플 좌표 28개,
가로/세로/확대 좌표·응답 검증·선택 영역 전송·타임아웃·취소 등 39개.

내장 브라우저에서 샘플 분석, 오탐 삭제, 누락 영역 추가, 숫자 좌표 수정,
유형 변경, 선택 제외와 JSON 반영, 확대, 세로 사진 이동·크기 조절, 되돌리기,
부분 판독·빈 결과·실패 후 재시도, PNG 생성 미리보기를 확인했습니다.
390px 모바일 화면에서 가로 넘침 없이 목록·좌표 편집이 표시되는 것도 확인했습니다.
테스트 JPEG의 파일 선택 → 미리보기 → 직접 드래그 추가 → 단색 가림 →
동일한 1137 × 1671 해상도의 PNG 미리보기도 확인했습니다.

브라우저 다운로드 요청은 실행되지만, 자동화 도구의 다운로드 파일 회수는 시간 초과로
파일 저장 위치까지 확인하지 못했습니다. 발표 전 Chrome/Edge에서 실제 다운로드 파일을 열어 확인하세요.
팀원의 사용성 평가, 실제 기기의 터치 조작, 팀 서버와의 종단간 연동은 아직 수행하지 않았습니다.
