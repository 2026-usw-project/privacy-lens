# Privacy Lens · 화면

사진을 공유하기 전 개인정보 영역을 확인하고 가리는 화면입니다.
디자인은 이 폴더의 시연본 그대로이고, 분석·판정·가림·검증은 **Privacy Lens 서버**
(저장소 루트의 `server.py`, Privacy Lens 2 백엔드)가 합니다.

## 실행

저장소 루트에서:

```bash
pip install -r requirements.txt
python run.py            # → http://127.0.0.1:8000 (화면과 API 가 같은 주소)
```

화면만 따로 띄우는 서버는 없습니다. 이전의 `server.mjs`(정적 파일만 내주던 4173 포트 서버)는
API 에 닿지 못해 삭제했습니다.

## 고치기

`dist/`가 편집 원본입니다. 고친 뒤에는 검사하고 다시 묶습니다. 서버는 묶인
`privacy-lens.html` 을 내줍니다.

```bash
node scripts/check.mjs            # 정적 검사 26개: 문법·요소 참조·파일 형식·샘플·스타일
node scripts/check-contract.mjs   # 계약 검사 49개: 서버 결과 → 화면, 화면 → 서버, 통신 오류
node scripts/build.mjs            # dist → privacy-lens.html
```

| 파일 | 역할 |
|---|---|
| dist/index.html, styles.css | 화면과 디자인 ([DESIGN.md](DESIGN.md)) |
| dist/app.js | 업로드·샘플·결과 목록·영역 편집·대기열 표시·미리보기·저장 |
| dist/core.js | 서버 결과 → 화면 영역, 고른 영역 → 서버 boxes, 좌표 변환 |
| dist/api.js | 서버 통신. 규격은 [API_CONTRACT.md](API_CONTRACT.md) |
| scripts/ | 검사·빌드 |

## 동작

1. **사진 선택** — JPG·PNG·WEBP·HEIC(서버에 `pillow-heif` 필요). 원본 파일을 그대로 서버로 보냅니다.
   브라우저가 못 여는 HEIC 는 분석 뒤 서버가 만든 미리보기로 보여 줍니다.
2. **분석** — 서버 대기열에 들어가 '대기 N건 · 약 N초' → '검사 중'. 머리글에는 전체 대기열이
   늘 보입니다. 취소하거나 사진을 바꾸면 기다리던 요청을 뺍니다. 판정 조건(문맥·결합 /
   심각도표 / 정규식만)을 머리글에서 바꿀 수 있습니다.
3. **확인** — 항목마다 가림 권장·검토 권장·참고(색), 내용 확인·일부·불가(선 모양), 근거 문장,
   인식된 문자열. 같은 문서에서 함께 나온 항목은 '함께 노출됨'으로 알려 줍니다.
   **기본으로 아무것도 고르지 않습니다.** 오탐 하나가 사진을 망치기 때문입니다.
   기울어진 글자는 기울어진 외곽선으로 표시됩니다.
4. **편집** — 영역 추가(드래그·중앙), 이동·크기·좌표 입력, 유형 변경, 삭제·되돌리기, 확대.
   기울어진 영역을 옮기면 외곽선도 함께 옮기고, 크기를 바꾸면 사각형이 됩니다.
5. **미리 보기** — '가림 결과'·'전후 비교'는 서버가 저장할 때와 같은 함수로 가린 모습입니다.
   가리는 방식은 흐리게(기본)·검은색. 흐리게는 글자 위에 블러를 거는 게 아니라 주변 색으로
   먼저 지운 뒤 흐리게 해서 원래 글자를 되살릴 수 없습니다.
6. **저장** — 서버가 가린 파일(JPEG)을 만들고 **다시 검사**한 결과를 보여 줍니다. 위치정보 등
   메타데이터는 항상 빠집니다. 아무것도 고르지 않아도 저장할 수 있습니다(위치정보만 지우기).

샘플 3종은 코드로 그린 가상 문서이고, 누르면 실제 서버로 분석합니다.

## 개인정보

- 사진은 분석·미리보기·저장 때만 이 서버로 보냅니다. 서버는 디스크에 쓰지 않고 로그에도 남기지 않습니다.
- 브라우저 저장소는 가리는 방식(흐리게/검은색) 기억에만 씁니다.
- 외부 글꼴·이미지·추적 코드를 쓰지 않습니다.
