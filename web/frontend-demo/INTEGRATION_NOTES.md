# 연동 기록

## 2026-10-04 — Privacy Lens 2 백엔드에 연결

백엔드를 Privacy Lens 2 로 교체하면서(브랜치 `feat/backend-pl2`) 이 화면을 실제 서버에 연결했습니다.
디자인(레이아웃·색·글꼴·컴포넌트)은 그대로 두고 동작만 바꿨습니다.

| 이전 시연본 | 지금 |
|---|---|
| 샘플 결과는 미리 정한 시뮬레이션, 내 사진은 수동 편집만 | 샘플·내 사진 모두 서버가 실제 분석 |
| 서버 연결 대화상자, 제안 API(`/api/analyze`, xywh `bbox`) | 같은 주소의 PL2 API ([API_CONTRACT.md](API_CONTRACT.md)) |
| 브라우저에서 PNG 로 다시 그려 전송 | 원본 파일 전송(서버가 방향 보정·위치정보 확인) |
| 브라우저 Canvas 가림: 모자이크·블러·단색 + 강도 | 서버 가림: 흐리게(정보 없음)·검은색, 미리보기도 서버 |
| 결과는 기본 전부 선택 | 기본 미선택(오탐 하나가 사진을 망친다) |
| 위험 유형 태그 | 가림 권장·검토 권장·참고 + 내용 확인·일부·불가 + '함께 노출됨' |
| 축 정렬 상자 | 기울어진 글자는 외곽선 |
| PNG 저장 | JPEG 저장 + 서버 재검사 결과 표시 |
| 발표 시연(90초 시나리오), 상황 재현 | 제거 |
| `server.mjs` 정적 서버(4173) | 삭제. `python run.py` 가 화면까지 내줌 |

브라우저에서 확인한 것: 샘플 분석, 흐리게/검은색 미리보기·저장·재검사, 30° 기울어진 JPEG 의
외곽선·위치정보, 대기열 '대기 3건 → 2 → 1 → 검사 중', 판정 조건 전환, 취소, 잘못된 파일, 직접 편집.

함께 찾은 화면 버그: `img.decode()` 는 탭이 가려져 있으면 끝나지 않아(Chromium) 미리보기가
멈췄습니다. `onload` 로 바꿨습니다.
