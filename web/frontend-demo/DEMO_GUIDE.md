# 발표 시연 · 팀 사용성 점검

## 준비

1. npm run dev 후 http://127.0.0.1:4173 접속.
2. 기본 연결이 **데모 · 서버 미연결**인지 확인.
3. 실제 개인정보 대신 내장 가상 샘플 사용.
4. 발표할 Chrome/Edge에서 미리 PNG 다운로드를 한 번 완료하고 결과 파일을 열어보기.
5. 이 데모의 분석 결과는 사전 정의한 시뮬레이션이라고 설명하기.

## 90초 시연 대본

| 시간 | 조작 | 설명 |
|---|---|---|
| 0–15초 | 90초 시연 시작 | “사진 속 배경 문서에도 개인정보가 있을 수 있습니다. 지금은 가상 샘플로 과정을 시연합니다.” |
| 15–30초 | 주소 항목 클릭 | “목록의 유형과 근거를 누르면 사진의 같은 박스를 확인할 수 있습니다.” |
| 30–40초 | 오탐 · SAMPLE 문구 삭제 | “잘못 찾은 영역은 사용자가 삭제합니다. 실수하면 되돌릴 수 있습니다.” |
| 40–60초 | 영역 추가, 이메일 부분 드래그 | “놓친 영역은 직접 추가하고, 박스의 위치와 크기를 조절합니다.” |
| 60–75초 | 단색 → 전후 비교 | “선택한 부분만 가립니다. 확대해 작은 영역도 확인할 수 있습니다.” |
| 75–90초 | 가린 사진 저장하기 → PNG 다운로드 | “최종 이미지를 확인하고 촬영 메타데이터를 복사하지 않은 새 PNG로 저장합니다.” |

누락 이메일은 복합 문서 이미지의 오른쪽 아래에 있습니다.
작아서 드래그가 어렵다면 **중앙에 영역 추가** 후 아래 원본 픽셀 좌표를 입력하세요.

- 왼쪽 935, 위쪽 688, 너비 404, 높이 45
- 유형: 이메일
- 이 좌표는 **1440 × 1000 복합 문서 샘플 전용**입니다.

상단 체크리스트는 작업 흐름을 돕는 용도입니다. 추가한 영역이 이메일을 정확히 덮는지는 직접 확인하세요.
실제 AI 성능·개인정보 완전 제거를 판정하는 체크리스트가 아닙니다.

## 예외 상황 시연

| 시연 상황 | 확인할 화면 |
|---|---|
| 일부 판독 실패 | 판독 실패 표시, 기본 가림 선택, 확대·수동 확인 안내 |
| 탐지 결과 없음 | “안전하다는 뜻은 아니에요” 안내, 직접 영역 추가 가능 |
| 분석 실패 · 재시도 | 사진 미리보기 유지, 다시 분석 / 직접 편집 |
| 세로 사진 | 미리보기 → 분석, 확대·스크롤 중 박스 위치 유지 |
| 내 사진 | 서버 미연결 안내, 가짜 결과 없이 수동 편집 |

최종 영역 데이터 버튼에서 원본 픽셀 좌표와 선택된 영역만 담긴 JSON을 확인할 수 있습니다.
서버가 준비되지 않아도 백엔드 담당자와 연동 형식을 논의할 수 있습니다.

## 발표 전 확인

- 발표 장비의 화면 배율/브라우저 확대에 맞춰 창 크기 확인
- 사진 선택·드래그 업로드를 실제 브라우저에서 확인
- 가로/세로 사진, 확대 50%·200%·400%, 이동·크기 조절
- 단색 가림 범위와 저장 이미지 원본 해상도
- 다운로드 폴더의 실제 PNG 열기 및 메타데이터 확인
- 서버 시연은 백엔드 연동이 완료된 뒤 별도로 리허설
- 85% 재현율·15% 오탐률·5초 처리 시간은 측정 결과가 아니라 목표임을 구분
